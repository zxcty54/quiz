1. Hum Kaun Si Information Collect Karte Hain?

A. Website par (mocktester.online)

Website ek free practice platform hai. Yahan login ki zaroorat nahi. Automatic technical information collect hoti hai:

  • Browser type & device: aap mobile se aaye hain ya desktop se
  • IP address: security aur analytics ke liye
  • Cookies: aapka quiz score aur preferences save karne ke liye
  • Email: sirf tab jab aap khud humein mail karte hain

B. Android app mein

App chalaane ke liye account banana zaroori nahi hai. Lekin progress save karne ke liye app ek identity banata hai aur kuch data aapke phone se server par save hota hai:

  • Identity: ek random generated user ID (usr_…) aur aapke phone ka device ID (Android ID). Isi se aapki progress dobara mil jaati hai.
  • Profile (aap khud bharte hain): naam, district (zila), phone number, email — ye sab optional hai. Aap chahein to khaali chhod sakte hain.
  • Study history: kaun sa sawaal attempt kiya, sahi/galat, kitna time laga, topic, score, streak, mastery/badge progress, saved aur wrong questions.
  • AI usage records: jab aap AI features use karte hain to sawaal ka text, topic aur result record hota hai — sirf tab jab aapne AI data disclosure accept kiya ho (section 4).
  • Community content: aapke posts, comments, likes, poll votes, saved posts, aur aapki file hui reports — aapke handle ke saath.
  • Creator / Coaching data (agar aap apply karte hain): coaching ka naam, address, handle, category, verification PIN, aur aapke diye hue social links (Telegram/YouTube/Facebook).
  • Classroom data: agar aap kisi coaching ke batch mein admission code se judte hain, to aapka naam/identifier, test score aur accuracy us coaching ke dashboard mein jaata hai.
  • Notifications: push notification ke liye Firebase device token.
  • Feedback: agar aap app ke andar feedback ya sawaal mein galti report karte hain, to wo text aur (aap khud likhein to) contact info.

C. Hum kya collect NAHI karte

  • ❌ Aadhaar, PAN, bank account, card ya UPI details — kabhi nahi
  • ❌ GPS / precise location — app location permission maangta hi nahi
  • ❌ Contacts, SMS, call log, gallery, camera photos — inhe padhne ki koi permission nahi li jaati
  • ❌ IP address se location tracking — hum aapki IP se city nikal kar track nahi karte
  • ❌ Third-party ad networks — app mein koi ads SDK nahi hai
  • ❌ Aapka data kisi ko bechte nahi — bilkul nahi

📌 Technical baat: jab bhi koi app ya website internet se content laati hai, to aapka IP address us server ko dikhta hai — ye internet ka normal behaviour hai (hamare content CDN aur database par bhi yahi hota hai). Hum ise jaan-boojh kar aapki pehchaan ya location banane ke liye use nahi karte.

2. Hum Aapki Information Ka Use Kaise Karte Hain?

  • Aapki progress save karne ke liye: streak, score, saved questions, mastery — taaki app dobara kholne par sab wapas mil jaaye
  • Service improve karne ke liye: kaun se topics mushkil lag rahe hain, kaun se mocks zyada attempt ho rahe hain
  • AI jawab dene ke liye: aapka sawaal AI model tak bhejne ke liye (section 4)
  • Community chalane ke liye: posts, comments, likes, leaderboard, aur safety/moderation
  • Coaching classrooms ke liye: batch admission, test results, hall of fame
  • Technical problem fix karne: error trace karna
  • Aapse baat karne ke liye: aapke feedback ya email ka jawab dene ke liye
  • Notifications bhejne ke liye: naye mocks, results ya updates ki push notification (agar aapne allow ki ho)

3. Account Aur Data Deletion (Aapka Poora Data Kaise Mitayein)

Google Play ki policy ke mutabik, aur hamare apne usool ke mutabik, aapko apna account aur data khud delete karne ka poora adhikar hai. Iske do tareeke hain:

🅰️ Tareeka 1 — App ke andar (turant, sabse aasaan)

Profile → 🔐 Account & Data → Delete Account & Data
  • 1. App kholein aur neeche Profile tab par jaayein
  • 2. 🔐 Account & Data section tak scroll karein
  • 3. Delete Account & Data par tap karein
  • 4. Screen par dikhegi ki kya-kya erase hoga — padhein, phir “Delete everything” dabayein
  • 5. Deletion poori hote hi app onboarding par wapas chali jaayegi, ek nayi identity ke saath

Ye data delete hota hai

Server se (hamare database se):

  • Profile — naam, district, phone, email, user ID, device ID
  • Study history — saare attempts, scores, streaks, mastery, AI reports/insights
  • Saved questions, wrong questions, bookmarks, notifications
  • Community — aapke posts, comments, likes, poll votes, saved posts, aur aapki file hui reports
  • Creator profile, creator mocks aur classroom (batch) submissions — agar aapke paas hain
  • Daily challenge submissions aur event registrations

Aapke phone se: wahi sab kuch — profile, progress, saved/wrong questions, batch unlocks, mastery, consents, aur sign-in state.

Jaane-bujh ke rakha jaata hai (taki app dobara kaam kare): aapki UI preference (dark mode) aur pehle se download hua study content cache. Ye aapke baare mein personal data nahi rakhte.

Deletion ke baad kya bacha rehta hai

  • Moderation reports (safety record): agar aapne kisi post/user/AI jawab ke khilaaf report file ki thi, to wo report ek safety record hai — app use khud erase nahi kar sakta (warna koi bhi apni report chhupa sakta). Agar aap chahte hain ki wo bhi hat jaaye, to humein email karein — hum hata denge.
  • Backup / logs: database ke routine backups hamare hosting provider (Supabase) ki retention policy ke mutabik apne aap expire/rotate hote rehte hain; rotate hone ke baad deleted data unme bhi nahi bachta.
  • Community copies: agar kisi doosre user ne aapke post ka content kahin share/quote kiya hai, to wo unka content hai — hum aapka original post hata dete hain.

🅱️ Tareeka 2 — Email se (web request)

Agar aap app use nahi kar rahe, ya phone badal chuka hai, ya kisi aur ki taraf se request kar rahe hain, to humein email karein:

📧 contact.mocktester@gmail.com
Subject: MockTester Account Deletion Request
Email mein ye likh dein:
  • Aapka naam (agar diya tha) aur registered phone number ya email
  • Aapka user ID ya community handle (agar pata ho — app mein Profile section mein dikhta hai)
  • “Mujhe mera account aur poora data delete karwana hai”

Samay seema: hum 30 din ke andar aapki request poori karte hain, aur aapko confirmation mail bhejte hain. Zyada tar cases mein ye 2–7 din mein ho jaata hai.

⚠️ Deletion permanent hai. Delete hone ke baad progress, streaks, saved questions, creator profile ya batch data wapas nahi aa sakta. Isliye app delete karne se pehle zaroori cheezein (jaise apne notes ya scores ka screenshot) save kar lein.

Sirf app uninstall karna kaafi nahi

App uninstall karne se sirf phone ka local data jaata hai — server par aapki progress bachi rehti hai (taki reinstall par wapas mil jaaye). Poora data mitaane ke liye upar wala Delete Account & Data button ya email wala tareeka use karein.

4. AI Features — Aapka Data Kahan Jaata Hai

App mein AI-based features hain (AI doubt solving, explanation, mastery analysis). Inhe chalane ke liye aapka sawaal aur uska context third-party AI providers tak bheja jaata hai. Hum isse chhupaate nahi:

  • Kya bheja jaata hai: sawaal ka text, uske options, sahi jawab, topic/tag, aapka chuna hua jawab, aur aapka likha hua doubt — bas. Hum AI ko aapka naam, phone number, email ya district nahi bhejte.
  • Kiske paas jaata hai: pehle hamare apne Cloudflare Worker (proxy) par, phir wahan se AI providers — Groq (models: gpt-oss-120b, gpt-oss-20b) aur Google Gemini (models: gemini-…-flash).
  • Kyun: sahi aur tez jawab dene ke liye. Agar ek provider fail ho to doosra try hota hai.
  • Aapki marzi se: pehli baar AI feature use karne se pehle app ek AI Data Disclosure dikhata hai. Jab tak aap use accept nahi karte, AI usage record nahi hota. Aap ise baad mein bhi Settings se dekh sakte hain aur consent wapas le sakte hain.
  • Record: AI usage ka record hamare database (user_question_attempts, user_ai_insights) mein aapki study history ke saath save hota hai — aur account delete karte hi ye bhi delete ho jaata hai.
  • AI content par shikayat: agar AI ka jawab galat, offensive ya theek nahi lagta, to jawab ke paas Report button hai. Wo report seedha hamare moderation queue mein jaati hai.

🤖 AI jawab computer se banaya gaya content hai — galti ho sakti hai. Apne final answer ka cross-check apni kitab/syllabus se zaroor karein. AI ko hum insaan dwara likha gaya content pretend nahi karate.

5. Community Features (Posts, Comments, Likes) — Public Content

  • App mein ek community hai jahan aap post, comment, like aur poll vote kar sakte hain.
  • Aapka post aur comment PUBLIC hota hai — doosre users use dekh sakte hain. Isliye apna phone number, address, school ID ya koi bhi personal detail post mein mat likhein.
  • Aapki pehchaan ek handle se hoti hai (naam se nahi). Aap handle badal sakte hain.
  • Community use karne se pehle aapko Community Terms accept karne padte hain.
  • Safety tools: aap kisi bhi post/comment/user ko report kar sakte hain, aur kisi user ko block kar sakte hain. Reports hamare moderation queue mein jaati hain; hamari team review karti hai aur zaroorat par content ya account hata dete hain.
  • Spam, links aur abusive content ke liye automatic filters bhi lagae gaye hain.
  • Account delete karne par aapke posts, comments, likes, poll votes, saved posts aur reports aapke handle ke saath server se hata diye jaate hain (moderation record ke baare mein section 3 padhein).

6. Third-Party Services (Data Kiske Paas Jaata Hai)

Hum in services ka use karte hain. Ye sab apni privacy policies ke mutabik data handle karti hain:

  • Supabase (database, region: Singapore / ap-southeast-1) — aapka profile, progress, community aur AI records yahan save hote hain. Connection HTTPS/TLS par hota hai.
  • Cloudflare Workers (hamare proxy) — AI requests, content delivery aur notification/alert routing ke liye.
  • Groq aur Google (Gemini) — AI jawab generate karne ke liye (section 4).
  • Google Firebase Cloud Messaging — push notifications bhejne ke liye (device token Google ke paas jaata hai).
  • Google Sheets / Apps Script — aapka app feedback aur “sawaal mein galti” reports hamari team ki sheet mein save karne ke liye. Yahan aapka contact info sirf tab jaata hai jab aap khud likh kar dein; warna “Anonymous” likha jaata hai.
  • Telegram — sirf creator/coaching onboarding requests ke liye: jab koi coaching apply karti hai to uska naam, address, handle, category aur generated verification PIN hamari team ke private Telegram channel par jaata hai (approve/reject karne ke liye). Aam students ka data Telegram par nahi bheja jaata. Iske alawa users dwara bheji gayi “trick/shortcut” submissions bhi team ke channel par jaati hain (bina user ki pehchaan ke).
  • Content CDNs (jsDelivr, GitHub raw, statically.io, raw.githack) — study content (questions, current affairs) tez load karne ke liye.

Hum aapka personal data kisi ko bechte nahi, kisi ko marketing ke liye nahi dete, aur kisi ad network ke saath share nahi karte.

7. Cookies Aur Google Analytics (Website)

Website par hum Google Analytics ka use kar sakte hain ye samajhne ke liye ki kaun se pages zyada padhe jaate hain. Ye anonymous data hota hai — isse aapki personal pehchaan nahi hoti.

Aap browser settings mein cookies disable kar sakte hain, par isse quiz ka score save nahi hoga aur kuch features sahi se kaam nahi karenge.

App mein cookies ka use nahi hota — app local storage (SharedPreferences) use karta hai, jise aap section 3 wale deletion button se mita sakte hain.

9. Data Security

  • Saara communication HTTPS/TLS par hota hai. App plain (unencrypted) HTTP traffic allow hi nahi karta.
  • Database par Row Level Security policies lagi hain.
  • Secrets (API keys, tokens) app ke code mein khule nahi rakhe gaye — build ke waqt inject hote hain ya proxy ke peeche rehte hain.
  • Creator verification PIN jaisi sensitive cheezein sirf verification ke liye use hoti hain.

Phir bhi sach ye hai ki internet par 100% security guarantee koi nahi de sakta. Hum best practices follow karte hain; aap bhi apna phone lock aur updated rakhein, aur apna account kisi ke saath share na karein.

10. Data Retention (Data Kitne Din Rakhte Hain?)

  • App data: tab tak jab tak aap khud delete nahi karte. Delete karte hi server aur phone — dono se hat jaata hai (section 3).
  • Inactive study logs: purane analyzed attempt logs database ke cleanup routines se samay-samay par hat jaate hain.
  • Community posts: purane posts automatic cleanup policy ke mutabik hataye ja sakte hain.
  • Moderation reports: safety ke liye rakhe jaate hain; aapki request par hata diye jaate hain.
  • Email / feedback: sirf tab tak jab tak jawab dene aur issue fix karne ke liye zaroori ho.
  • Backups: hosting provider ki retention policy ke mutabik apne aap rotate/expire hote rehte hain.
